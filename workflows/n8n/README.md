# AIGC n8n Template Boundary

These workflow templates are local placeholders for future n8n setup.

They are safe to review because they contain:

- no credential blocks
- no live endpoint values
- no production URLs
- no local machine paths
- dry-run mode
- disabled external-action nodes
- human approval wait-step placeholders
- AIGC audit and correlation fields

The templates do not execute anything by themselves. A future live connector requires a separate live action request, live action permit, allowlist check, idempotency key, kill-switch check, and result audit.
