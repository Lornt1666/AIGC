# AIGC Canonical Domain Glossary

Status: vocabulary convergence contract.

Use these names for new architecture. Legacy names are mapped before deletion or refactor.

- User — product account principal.
- Operator — accountable human principal exercising consequential authority.
- Employer — organization/person procuring authorized work.
- EmployerVault — confidentiality and data-isolation boundary for one employer.
- EmployerPreference — professional operational preference, not psychological profiling.
- Opportunity — candidate digitally executable work engagement.
- OpportunitySource — permitted source/platform origin.
- OpportunityAssessment — qualification/economic/fit assessment.
- FraudAssessment — legitimacy and scam-risk determination.
- CapabilityRequirement — skill/authority/credential/tool requirement extracted from work.
- CapabilityEvidence — benchmark/delivery/review evidence supporting a capability claim.
- CapabilityProfile — current evidence-backed capability state.
- Proposal — reviewable engagement proposal.
- ApplicationDraft — truthful application material pending external authorization.
- Engagement — employer relationship with agreed work context.
- Contract — accepted governing terms.
- StatementOfWork — bounded scope/deliverables/terms for work.
- Requirement — testable employer/work obligation.
- AcceptanceCriterion — objective or reviewable condition for employer acceptance.
- ChangeOrder — authorized change to scope/cost/deadline/criteria.
- WorkOrder — executable bounded unit under an engagement.
- Task — atomic or decomposable work item.
- TaskDependency — ordering/data dependency between tasks.
- AgentRole — bounded capability profile.
- AgentCell — small coordinated group of roles for a task/subsystem.
- Swarm — temporary bounded multi-agent organization for an engagement/work order.
- ComputeRequirement — workload capability/security/privacy/jurisdiction/quality/budget constraints.
- ComputeCandidate — possible CPU/GPU/NPU/model/API/tool execution resource.
- ComputeRoute — selected admissible execution route or heterogeneous portfolio with rationale.
- ToolInvocation — governed invocation record.
- WorkEvent — timestamped work/activity/evidence event.
- WorkLedger — multi-clock chronology of work.
- CostLedger — compute/tool/human/specialist/expense accounting.
- Artifact — produced intermediate or final object.
- Deliverable — contract-relevant artifact/package.
- Verification — independent check against requirements/standards/acceptance criteria.
- RevisionRequest — requested correction/change within current scope.
- Acceptance — employer or governed acceptance state.
- InvoiceDraft — contract-derived reviewable invoice; does not authorize sending or collection.
- PaymentRecord — observed/authorized payment state, never fabricated.
- EmployerFeedback — employer-provided quality/relationship input.
- CapabilityUpdate — evidence-backed change to capability profile.
- ReputationEvidence — non-fabricated performance evidence.
- SwarmScheduler — decomposition, dependency, specialist, compute, verifier and critical-path coordinator.
- ComputeExchange — quality/security/privacy/jurisdiction/confidentiality-aware multi-objective procurement of admissible execution resources. Cost is a dimension, not the supreme objective.
- VerificationTribunal — independent challenge/review surface before delivery.
- EmployerPolicyCompiler — converts employer constraints into enforceable execution policy.
- DefinitionOfDone — predeclared completion/verification criteria for a deliverable.
