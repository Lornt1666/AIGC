## Purpose

Create a deterministic, revision-bound receipt proving which CI dependency manifest and workflow bytes were inspected, which external action references were observed, and whether the observed dependency topology matched the reviewed policy.

The dependency manifest describes approved policy. The receipt records the evidence generated by applying that policy to one checked-out repository revision. Neither artifact grants approval, merge authority, deployment authority, credential use, connector execution, or external-action authority.

## Receipt contract

The receipt records:

- schema version and deterministic receipt identifier;
- creation time;
- checked-out source revision;
- evidence class;
- manifest identity, version, path, and SHA-256 digest;
- workflow root;
- workflow paths and SHA-256 digests;
- observed action topology;
- mismatch list;
- `PASS` or `FAIL` conclusion;
- mandatory operator review;
- prohibited automatic merge;
- no AIGC runtime external action.

A `PASS` receipt cannot contain mismatches. A `FAIL` receipt must contain at least one mismatch.

## Architecture boundary

```text
Dependency manifest
    -> repository-wide workflow inspection
    -> revision and occurrence comparison
    -> deterministic evidence receipt
    -> CI artifact
    -> operator review
```

The change is confined to the governance and CI evidence planes. It adds no application runtime, API, UI, persistence, identity, connector, or deployment capability.

## Security and privacy boundary
