# 0. Prime Definition

AIGC — Artificial Intelligence Gladiator Colosseum — is a governed, evolutionary, multimodal, multi-agent system that ingests any objective, decomposes it into knowledge structures, classifies it by domain/risk/authority/modality, assigns specialized Gladiator Agents, generates or simulates outputs, validates them, routes external action through approval gates, logs everything, and evolves from every ecosystem encounter.

Professional target:

```text
maximum capability
minimum uncontrolled authority
maximum articulation
minimum ambiguity
maximum output quality
minimum hidden risk
maximum evolution
minimum governance decay
```

Prime law:

```text
Anything may enter the Colosseum.
Everything must be articulated.
Only validated, authorized, approved action may leave it.
Every encounter must improve the system without weakening governance.
```
