# PIBC-v1 Non-Scope

This implementation does not include or authorize:

- live OIDC, OAuth, SAML, Google, Microsoft, GitHub, or workload-identity configuration;
- token issuance, token refresh, MFA enrollment, password handling, credential provisioning, or secret storage;
- hosted login UI, public API exposure, production deployment, DNS, certificates, or ingress;
- connector activation, job application, bidding, messaging, contract acceptance, payment, delivery, or external action;
- deletion or consolidation of existing identity, authorization, audit, Quest, or persistence modules;
- production-readiness promotion based solely on plans, documentation, schemas, or source-file presence;
- merge or deployment without exact-head CI and a separate operator decision.
