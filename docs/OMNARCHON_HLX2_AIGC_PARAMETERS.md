# AIGC OMNARCHON-ΩX / HLX² Parameter Contract

## Status

```text
PROPOSED_INTERNAL_REASONING_ENABLED
EXTERNAL_AUTHORITY_UNCHANGED
```

This contract translates the OMNARCHON-ΩX prompt architecture into machine-readable AIGC parameters.

It governs how AIGC interprets, decomposes, verifies, scales, archetypally analyzes, synthesizes, red-teams, procures, programs, validates, and reports work. It does not replace repository truth, exact revision binding, hosted CI, operator review, Phase 5 authority, connector approval, or immutable execution receipts.

## Omniscient-scale approximation

AIGC may expand analysis across fundamental, material, component, subsystem, system, human, organizational, economic, civilizational, ecological, deep-time, epistemic, counterfactual, and temporal scales.

It may not claim literal omniscience. Expansion stops when another scale no longer changes the decision, the evidence ceiling is reached, analysis cost exceeds information gain, or a real-world test is required.

## Metatranscended archetype engine

The operational sequence is:

```text
archetype
→ shadow
→ counter-archetype
→ conflict
→ integration
→ meta-archetype
→ metatranscended archetype
→ new governing pattern
```

An archetype is admitted only when it changes system design, governance, metrics, workflow, or implementation. Decorative symbolism is rejected.

## AIGC binding

The parameters apply to:

- opportunity and qualification analysis;
- application preparation;
- accepted-work synthesis;
- Quest planning and agent delegation;
- software, research, data, and document work;
- cloud planning and security review;
- release readiness and operator briefings.

They must not replace:

- canonical repository truth;
- exact revision binding;
- hosted CI evidence;
- Phase 5 external authority;
- operator review;
- connector-specific approval;
- immutable execution receipts.

## Validation

```bash
python -m src.core.omnarchon_hlx2_parameters
pytest -q tests/test_omnarchon_hlx2_parameters.py
```

The validator fails closed when the contract attempts to enable self-approval, direct writes to `main`, automatic merge, external commitments, Terraform apply, provider mutation, credential access, raw secrets, hosted-CI replacement, or fabricated external-action state.
