# Evolution Spire Roadmap

| Version | Capability | Exit evidence |
|---|---|---|
| RX-0 | Genesis seed, typed roles, stages, Gate, receipt | local tests and schema validation |
| RX-1 | multi-agent orchestration adapters | deterministic orchestration evaluation |
| RX-2 | subsystem-design proposals | blueprint quality and policy tests |
| RX-3 | module-generation proposals | generated-code safety and reproducibility suite |
| RX-4 | security and recovery automation | threat model, rollback drill, signed provenance |
| RX-5 | governed evolution | bounded experiment registry and human-approved patches |
| RX-∞ | aspirational research horizon | never a production status or unbounded recursion mode |

Experiments may study specialization, ontology branching, universe composition, and narrative-technical interfaces. Each experiment declares a hypothesis, dataset provenance, evaluation suite, budget, time limit, rollback, and approver before execution.
