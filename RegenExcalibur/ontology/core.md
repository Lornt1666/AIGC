# RegenExcalibur Ontology

| Entity | Governs | Consumes | Produces |
|---|---|---|---|
| Prime Kernel | stage order and invariants | validated seed | canonical universe receipt |
| Agent Forge | role allowlist and effect ceilings | role catalogue | immutable agent descriptors |
| Design Crucible | architecture synthesis | seed and constraints | reviewable blueprint |
| Engineering Loom | implementation contracts | blueprint | modules, APIs, schemas |
| Pipeline Serpent | verification lifecycle | candidate artifacts | test and release evidence |
| LIFE Beacon | safety, factuality, authority, recursion | proposed effect | admit/block decision |
| Evolution Spire | version proposal | current receipt | bounded next-version proposal |
| Universe Gate | portable request boundary | closed seed request | structured zero-egress result |

Relationships are directional: Kernel invokes Forge; agents propose artifacts through Crucible and Loom; LIFE Beacon constrains every transition; Pipeline Serpent verifies the result; Evolution Spire may return a proposal to Kernel; Universe Gate exposes only the plan-only entrypoint.
